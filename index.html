登録不要ですぐ使える、シンプルな無料Webツール集

  • 棋譜暗記道場

    将棋の定跡を盤上で指して覚えるツール。定跡ツリーで変化を整理し、先手・後手・両方の立場で全変化を出題します。KIFファイルの読み込み・書き出しに対応。

  • 決まり字道場

    百人一首の決まり字を、取り札を選んで覚えるツール。1字決まりから大山札まで字数別・番号別・苦手な札だけで練習でき、まぎらわしい友札が選択肢に混ざります。

  • hamu

    ハムスターの「ハム」を操作して、ジャンプアクションで転がってくるイガグリをよけていくゲーム。自分でコースを作ったり、フレンドとバトルしたりして遊べます。

  • Name It First

    まだ世界の誰もつけていない名前をつけられるか挑戦するゲーム。新しい名前を思いつくたびに住人が増え、たき火ひとつから世界の首都まで自分の街が育っていきます。英語・日本語など11言語に対応。

kdking tools について
